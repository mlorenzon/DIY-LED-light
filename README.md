# Inflatable DIY LED panel light

A 48 × 68 cm bi-colour (2700–5500 K, CRI 95) soft light with no rigid frame: a bicycle inner tube in denim sleeves inflates to hold a diffusion sheet off the LED strips. It hangs on a wall, packs flat, and cost under AU$200 in parts.

The full build guide with parts list, diagrams and photos is published with GitHub Pages: **https://mlorenzon.github.io/DIY-LED-light/**

## What's here

- `index.html` – the complete guide (single file, inline CSS and SVG diagrams, no build step)
- `images/` – stills from the build video
- `LICENSE` – CC BY-SA 4.0

## Publishing your own copy

1. Fork this repository.
2. In the fork go to **Settings → Pages**, set *Source* to "Deploy from a branch", pick `main` and `/ (root)`, save.
3. A minute later the guide is live at `https://<your-username>.github.io/DIY-LED-light/`.

## Contributing

Built one? Changed something? Found a mistake? Open an issue or a pull request. Ideas that would be especially welcome are listed at the bottom of the guide: a larger version, battery power, hanging hardware, a cheaper reflector, a printable pattern, and alternative dimmers.

Everything is plain HTML, so edits are easy: the step text lives in `<section>` blocks and each diagram is an inline `<svg>`.
